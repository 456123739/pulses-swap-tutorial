# Pulses Swap 使用教程

Pulses Swap（Tacz 枪包一键切换工具）的交互动画使用教程。

## 使用方法

1. 点击下方链接下载 `PulsesSwap-Tutorial.html`
2. 双击用浏览器打开即可观看

## 特性

- 玩家篇 12 段 + 开发者篇 13 段分镜动画
- 液态玻璃风格 (iOS 26)
- 自绘 SVG 图标（零 emoji 依赖，任何系统都能正常显示）
- 苹果式缓动曲线 + 3D 镜头 + 背景视差
- 单 HTML 文件自包含，无需安装任何软件
